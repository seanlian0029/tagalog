Beginner Help

You will not need to edit code during normal use.

1

Normal database update

  1. Download Current Excel.
  2. Edit it and save as .xlsx.
  3. Upload it here.
  4. Read the validation preview.
  5. Press Publish and wait for success.
2

Add a customer PIN

  1. Open PINs.
  2. Enter exactly 4 digits.
  3. Choose FULL or categories.
  4. Press Add PIN & Publish.
3

One-time secure setup

  1. Create the secure admin service.
  2. Save the Admin username/password there—not in Excel.
  3. Connect your private Excel storage and GitHub website repository.
  4. Connect analytics.

Where is the Admin password saved?

Not in Excel and not in public JavaScript. It is saved as a protected secret in the secure admin service. The website ZIP includes a connection checklist in BEGINNER_SETUP.md.
